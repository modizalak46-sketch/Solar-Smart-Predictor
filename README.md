# ☀️ Solar Energy Forecaster Pro

An AI-powered dashboard that predicts solar energy generation in real-time using Machine Learning and Live Weather APIs.

## 🚀 Features
- **Live Weather Integration:** Fetches real-time cloud cover & temperature using OpenWeatherMap API.
- **ML Model:** Built with **XGBoost Regressor** for high accuracy.
- **Dynamic Location:** Predicts output for any city based on user input.
- **Financial Insights:** Calculates daily savings in INR (₹).
- **Maintenance Alerts:** Tracks panel health based on cleaning cycles.

## 🛠️ How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run the app: `streamlit run app.py`
